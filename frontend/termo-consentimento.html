Termo de consentimento para tratamento de dados pessoais

Lei Geral de Proteção de Dados Pessoais — Lei nº 13.709/2018 (LGPD)

Partes

Psicóloga responsável (controladora dos dados): CRP
Contato para assuntos de dados pessoais:

Paciente (titular dos dados): CPF

1. Quais dados são tratados

  • Identificação e contato: nome, CPF, e-mail e telefone.
  • Agenda e pagamentos: datas das sessões, faltas, valores e formas de pagamento.
  • Registros de atendimento (evolução das sessões) — dados pessoais sensíveis, referentes à saúde (LGPD, art. 5º, II).

2. Para que são usados

  1. Organizar a agenda e os atendimentos.
  2. Manter o registro documental dos atendimentos, obrigatório para a psicóloga (Resolução CFP nº 001/2009).
  3. Controlar pagamentos.
  4. Opcional: enviar lembrete das sessões por e-mail. O e-mail diz apenas "lembrete de atendimento", com data e hora.
    (   ) Aceito receber lembretes por e-mail    (   ) Não aceito

Os dados não são usados para publicidade nem vendidos ou cedidos a ninguém.

3. Como são protegidos

Os dados ficam num sistema com acesso exclusivo da psicóloga, protegido por senha. Os registros de atendimento são guardados criptografados, e há cópias de segurança periódicas. Para funcionar, o sistema usa prestadores de serviços de tecnologia (hospedagem, banco de dados e envio de e-mail), que tratam os dados apenas para essa finalidade e sob obrigação de segurança; alguns desses serviços podem estar localizados fora do Brasil. 4. Por quanto tempo

Os registros de atendimento são guardados por, no mínimo, 5 anos (Resolução CFP nº 001/2009), mesmo após o fim do acompanhamento. Depois desse prazo, podem ser eliminados.

5. Seus direitos

A qualquer momento, mediante pedido à psicóloga, você pode: confirmar que seus dados são tratados e ter acesso a eles; corrigir dados incompletos ou desatualizados; saber com quem eles são compartilhados; e revogar este consentimento (LGPD, arts. 8º, §5º, e 18).

A revogação interrompe o que depende do seu consentimento, como os lembretes por e-mail. Os registros que a psicóloga é obrigada a guardar (item 4) são mantidos pelo prazo mínimo (LGPD, art. 16, I).

6. Declaração

Declaro que li este termo, que tive a oportunidade de tirar dúvidas e que consinto com o tratamento dos meus dados pessoais, inclusive os dados sensíveis de saúde, para as finalidades descritas acima.
